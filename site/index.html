About the Riemann proof map

An interactive reading map by Miroslav Lžičař for the Lean proof released by Levent Alpöge. Source code and editable labels ↗

How to read a branch

Start at a conclusion and follow the declarations its Lean type or proof references. If every path to a declaration passes through the same intermediate result, that result dominates it. Connecting each declaration to its closest such predecessor gives a dominator tree.

The map computes that tree separately for classical RH and Dirichlet GRH. TMAP arranges the classical tree in two dimensions. Shared declarations keep their positions in the Dirichlet view, so you can switch conclusions without losing your place. At large hubs it groups siblings by similarity in their names and module paths. The optional similarity links show those groupings. Selecting a node reveals its actual dominators.

Walking a proof

A reading path follows real compiled references. Read forward from an input to the conclusion or backward to ask what a result uses. Many other paths exist. Project leaves can depend on Lean or Mathlib outside this map.

Progress measures dependency depth. Groups of mutually referring declarations count as one stage. Each stage is one more than the deepest prerequisite stage, and the selected conclusion is 100%. This is a structural scale. The source archive supplies no per-declaration discovery times.
